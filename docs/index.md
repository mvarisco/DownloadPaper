# IFQ Downloader

Strumento personale e automatizzato che scarica ogni giorno l'edizione digitale
del quotidiano a cui sono abbonato (ilfattoquotidiano.it) e la archivia nel mio
Google Drive personale.

Non è un prodotto pubblico: è un progetto a uso esclusivamente privato
dell'autore, pubblicato come repository solo per gestire il codice e
l'automazione tramite GitHub Actions.
